## 🌟 核心功能特色

### 1. 📱 早期溫情關懷話術（逾期 1~2 個月）
- 依據《呆帳處理辦法》第 11 條「黃金介入期」設計。
- 一鍵生成：
  - **溫情同理心關懷型**電訪腳本
  - **紓困展延／分期協商型**電訪腳本
  - **幹部正式提醒型**電訪腳本
  - **LINE 官方帳號 / 簡訊親切通知文案**（親切提醒、正式催繳、法催前最後告警）。

### 2. ⚖️ 司法院標準法催公文一鍵排版產出（逾期 3 個月以上）
- **精簡流程**：免去存證信函，法催直接從《民事支付命令聲請狀》起步。
- **利息與違約金彈性輸入**：因儲互社各社規程不同，支援**直接手動輸入金額**（亦附選用之按日試算輔助），並**自動轉為司法院專用中文大寫金額**（例：`新臺幣貳拾壹萬元整`）。
- **強制執行標的全面升級**（核取方塊自由勾選）：
  - 🛡️ **扣押人身保險解約金**：依**最高法院 108 年度台抗大字第 897 號民事大法庭裁定**，囑託壽險公會查調保單並扣押保單價值準備金/解約金。
  - 🏦 **查調金融機構存款**：囑託【銀行公會】查調債務人於全台銀行、郵局、信用合作社之存款帳戶並予扣押。
  - 💼 **扣押每月 1/3 薪資**：強制執行法第 115 條之 1。
  - 📑 **查調國稅局全年度財產及所得清單**。
  - 🏠 **查封拍賣不動產**。
- **支援 3 大標準公文**：
  1. 《民事支付命令聲請狀》（民事訴訟法第 508 條）
  2. 《民事強制執行聲請狀》（強制執行法第 4、6、115 條）
  3. 《民事聲請換發債權憑證狀》（強制執行法第 27 條）
- **輸出支援**：A4 標準訴狀列印、一鍵複製全文、純文字檔下載。

### 3. ⏰ 5 年消滅時效到期鬧鐘與台帳管理
- 依《民法》第 126 條（利息 5 年）與第 137 條第 3 項（換發憑證重行起算 5 年）。
- **四色時效燈號即時監控**：
  - 🟢 **安全期**：剩餘 > 180 天
  - 🟡 **預警期**：剩餘 90 ~ 180 天（提示準備換證）
  - 🔴 **緊急告急**：剩餘 < 90 天（請立即具狀換證）
  - ⚫ **已逾期**：時效已屆滿
- **📅 一鍵匯出 `.ics` 行事曆鬧鐘**：可直接匯入 Google Calendar / Outlook / Apple 日曆，內建**「到期前 6 個月」、「到期前 3 個月」、「到期前 1 個月」自動推播鬧鐘提醒**。
- **⚖️ 一鍵連動換證**：在台帳中點擊「一鍵換證」，自動將該案件案號與債權金額帶入《換發債權憑證聲請狀》。
- **📊 資料備份與還原**：支援 Excel 相容之 CSV 台帳清冊匯出、JSON 全量備份與還原。

### 4. 🔒 100% 本地離線安全與個資法合規
- 採用 **Client-side Rendering（純前端本地運算）** 與 `LocalStorage` 離線儲存。
- 借款人姓名、身分證字號、債權金額與法院案號等機敏資料，**絕不回傳或儲存於任何外部伺服器**。

## ⚖️ 法律依據與實務指引

1. **保險契約解約金扣押**：
   - **最高法院 108 年度台抗大字第 897 號民事大法庭裁定**：執行法院於必要時，得核發執行命令終止要保人（債務人）之人身保險契約，命第三人保險公司償付解約金支付債權人。
2. **債權憑證 5 年消滅時效**：
   - **民法第 126 條**：利息之各期給付請求權，因五年間不行使而消滅。
   - **民法第 137 條第 3 項**：經執行名義確定之請求權，因中斷而重行起算之時效期間為五年。
3. **薪資扣押額度**：
   - **強制執行法第 115 條之 1**：扣押每月薪資以 1/3 為原則，並維持債務人及其受扶養親屬之生活所必需。
